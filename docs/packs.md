# Пакеты сценариев

Стандартные шаблоны и подписи кнопок находятся в `config/base.json`. В исходниках это `public/config/base.json`.

По умолчанию установлен минимальный пакет `minimal.json`: Диагностика → Сведения о компьютере. Он использует inventory и не изменяет настройки Windows. Дополнительные пакеты помещайте в `public/config/packs` для разработки либо в `config/packs` рядом с установленным exe. Сборка настольного приложения копирует папку config. Перезапустите приложение после ручного добавления файлов. Браузерная сборка включает пакеты, существующие во время сборки; для новых файлов её нужно пересобрать.

Кнопка «Конфигуратор пакетов» открывает визуальный редактор. Выберите существующий пакет, создайте новый или импортируйте JSON. На вкладках доступны уровни навигации, шаги формы, поля и ограничения, подписи кнопок, действия с параметрами, изменение порядка и предпросмотр. Проверка учитывает конфликты с остальными пакетами. В настольной программе «Сохранить в config/packs» записывает пакет и обновляет навигацию. В браузере используйте «Скачать JSON» и перенесите файл в папку packs. Изменение ID создаёт отдельный пакет; для изменения существующего сохраните его ID.

Каждый JSON содержит уникальный `id`, массив названий `path`, `wizard` и `steps` с действиями. Общие папки пути объединяются. Повторный id, занятый путь или пересечение папки с мастером вызывает ошибку с именем файла. Профилей и выбора профиля нет. Старые настройки браузера не используются.

Шаги мастера: необязательные `form`, затем `review`, `execution`, `result`. Поля форм поддерживают text, number, select, checkbox, textarea. Действия ссылаются на стандартные шаблоны command и inventory. В браузере действия только показываются; команды выполняются в настольной программе.
